깃허브 열쇠 등록

토큰은 로그인 비밀번호로 암호화해서 이 브라우저에만 저장해요. 파일에는 남지 않아요.

토큰 만드는 법
  1. 깃허브 → 프로필 사진 → Settings
  2. 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. 이름: aisimalseo-admin, 기간: 90일
  4. Repository access: Only select repositories → aisimalseo-site
  5. Permissions의 Contents를 Read and write로
  6. Generate token → github_pat_로 시작하는 값 복사
